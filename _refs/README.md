# _refs — 참고용 이미지 (배포 안 됨)

구글/크롤링으로 모은 패키지 사진을 여기에 둔다.
빌드에 포함되지 않으므로 사이트에 올라가지 않는다. 화면 구성을 확인하는 용도.

파일명은 제품 slug 와 맞춰둔다 (`honey-butter-chip.jpg`).
나중에 직접 찍은 사진으로 교체할 때 그대로 `public/images/products/` 로 옮기면 되고,
옆에 `honey-butter-chip.credit.txt` 에 `own photo, 2026-10-01` 처럼 한 줄 적으면 빌드가 통과한다.

## 2026-09-13 제조사 사이트에서 수집한 20장

약과를 뺀 20종의 사진을 각 제조사 공식 사이트(오리온·농심·롯데웰푸드·해태·크라운·삼양·오뚜기)에서 받았다.
사진마다 옆에 `<slug>.source.txt`(원본 URL·페이지·수집일)가 있다.

**`.credit.txt` 가 아니라 `.source.txt` 인 이유:** 빌드 게이트는 `.credit.txt` 만 있으면 통과시킨다.
제조사 이미지는 사용 허락을 받지 않았으므로, 파일을 옮겨도 게이트를 통과하지 못하게 이름을 다르게 뒀다.
배포하려면 직접 촬영으로 교체하거나 제조사 허락을 받은 뒤 `.credit.txt` 를 새로 쓴다.

`vanilla/` 버전은 `node vanilla/build-data.mjs` 를 실행하면 이 폴더의 사진을 자동으로 붙인다(로컬 확인용).

## 로컬에서 참고 이미지를 화면에 붙여 보고 싶을 때

```bash
npm run dev:refs   # _refs 를 public 에 심볼릭 링크로 걸고 dev 서버 실행
```

이 상태로는 절대 배포하지 않는다. `npm run build` 가 출처 없는 이미지를 막는다.
