# K-Snack Basak — HTML/CSS/JS 버전

빌드 도구 없이 `index.html` 을 더블클릭하면 열린다. Astro 버전(`../src`)과 같은 데이터를 쓴다.

```
index.html      뼈대 (헤더·하단 탭바)
style.css       POP 디자인. 모바일(<768px) 기준, PC는 768/1024px에서 확장
app.js          해시 라우팅 한 페이지 앱 — 홈 / 제품 상세 / 가이드 목록 / 가이드 / 내 목록
data.js         자동 생성. 직접 고치지 않는다
build-data.mjs  products.json · guides.json · 사진 목록 → data.js
```

## 데이터나 사진을 바꾼 뒤

```bash
node vanilla/build-data.mjs
```

## 바꾸기 쉬운 곳

- **사이트 이름:** `app.js` 맨 위 `SITE_NAME` 한 줄 (+ `index.html` 의 `<title>`·로고 기본값)
- **화면 문구(EN/JA/KO):** `app.js` 의 `UI`
- **기분별 타일:** `app.js` 의 `MOODS` — 데이터에 있는 값(종류·매운 정도·선물용)으로만 거른다

## 화면

- 홈: 히어로 + 매대 검색기 콘솔, 과자 이름 띠, "오늘 어떤 맛?" 타일, 3단계 사용법, 가이드, 전체 과자(검색·종류·안매운/매운/낱개포장/선물용)
- 상세: 사진, 가격·매운 정도, **매대에서 찾는 법(노랑 카드)**, 주의, 맛·식감·누구에게, 맛별 버전, 기본정보
- 모바일: 하단 탭바(홈·가이드·내 목록), 상세에선 하단 고정 "목록에 담기"
- 내 목록: localStorage 저장, 매장에서 체크
- 언어: EN / 日本語 / 한국어. 첫 방문은 브라우저 언어

## 디자인 기준

참고 디자인 문서에서 고른 것: 전기 노랑(#faff69) 하나를 주인공으로, 굵은 Inter + 좁은 자간,
크게 박는 숫자, 노랑 CTA, 코드 창 형태의 콘솔 카드.
과자 서비스에 맞게 바꾼 것: 크림색 바탕, 검정 테두리 + 오프셋 그림자, 카테고리별 캔디 색, 히어로·푸터만 검정.

## 정보가 덜 찬 제품

`products.json` 에서 `"status": "incomplete"` 인 제품(현재 비쵸비)은 vanilla 에만 보이고 Astro 빌드에서는 빠진다.
가격·맛 등이 `null` 이거나 없으면 화면에 "확인 중" 으로 뜨고 해당 카드는 숨는다.

## 사진

`vanilla/images/<slug>.jpg` → 없으면 `../_refs/<slug>.*` 순서로 붙인다. 둘 다 없으면 한글 이름 카드.

지금 붙어 있는 21장은 전부 `_refs/` 의 **제조사 사이트 이미지(사용 허락 없음)** 다.
화면에 "Reference photo" 표시가 뜬다. 이 상태로 배포하지 않는다.
